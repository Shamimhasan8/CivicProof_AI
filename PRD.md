# Product requirements

## Goal
Help a citizen understand, prepare, and preserve evidence for Bangladesh e-Passport re-issue. The MVP is a narrow synthetic demonstration for International AI Builders Congress 2026, Team AGI.

## Acceptance criteria and current evidence

| Requirement | Acceptance | Status |
|---|---|---|
| Document preflight | PNG/JPEG/PDF/TXT validation, actual extraction, correction and confirmation, comparison | Implemented; text extraction and comparison tested; image OCR verification recorded separately |
| Requirements | Conditions change applicability; cited passages remain inspectable | Implemented, synthetic tests and browser checks |
| Unexpected demands | Unknown demand abstains and offers respectful next step | Implemented, synthetic tests and browser checks |
| Timeline | Add/delete/export citizen-reported synthetic event with timestamp and evidence note | Implemented |
| Clarification | Bangla/English editable draft, copy and download; never submit | Implemented |
| Source governance | Versions, scope, publication uncertainty and access method visible | Implemented; specialist review pending |
| Privacy | Synthetic-only UI; local case state, user deletion and export | Implemented; no legal compliance certification |
| Live docs | Truthful model, retrieval, data, evaluation and roadmap inventory | Implemented |

## Boundaries
No real identity processing, government status tracking, legal decision, public rule editor, semantic RAG, autonomous complaint filing, or provider LLM in this release. Only e-Passport re-issue is available; other services are explicitly planned.

## Usability
Bangla default, English toggle, keyboard focus, clear error/empty/loading states, responsive app layout. The technical portal and some evidence statuses remain in English; full Bengali technical documentation is future work.
