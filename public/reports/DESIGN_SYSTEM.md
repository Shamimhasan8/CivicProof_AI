# CivicProof design system

A quiet civic workspace: warm-white canvas, white panels, forest-green actions, sage preparation surfaces, restrained amber uncertainty. The shield/check symbol is custom application branding, not a government seal.

## Tokens
- Canvas #fafbf8; panel #ffffff; primary #225b48; primary ink #233c34.
- Sage surface #eaf0e4; amber emphasis #8d6329; line #e7eae5.
- System typography: Inter / Noto Sans Bengali / Segoe UI / Arial fallback; Bengali UI by default.
- Sidebar 250px desktop; mobile overlay navigation below 760px.
- Main page padding 39px desktop, 16px small mobile; 10–14px panel radii; 7px action radii.
- Icons: Lucide React. Decorative document illustration: CSS and SVG icons, no stock images or generated government assets.

## Interaction
Every primary navigation, upload, filter, conditional checkbox, comparison gate, timeline operation, draft control, language selection and download has implemented behavior. Empty states invite a useful action. Loading and extraction errors stay visible. Keyboard focus uses a 3px outline; reduced-motion preferences disable transitions. Manual layout inspection is recorded in docs/QA.md. A full independent accessibility audit has not been performed.

No Figma file was created. The live working prototype, source CSS and actual screenshots are the design evidence.
