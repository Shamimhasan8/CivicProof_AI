| 0–20s | Overview; show independent-service and synthetic badges | A government service can be online, while the next step still feels uncertain. What if two documents spell your name differently? CivicProof identifies the spelling discrepancy, while the dates remain consistent. It preserves original and normalized values and links the supporting application guidance. It does not call this fraud, authenticate an identity, or decide eligibility. |
| 68–94s | Requirements; set passport lost; open R13 passage | The checklist changes with the circumstances. Select a lost passport, and the original general-diary requirement becomes applicable. We can inspect the exact official passage, clause, source version, and review status. These are draft mappings awaiting specialist review. Where a newer correction circular may matter, CivicProof asks for official clarification instead of treating an older checklist as conclusive. |
| 94–122s | Request checker; bank statement; show abstention | Now imagine a citizen reports being asked for a bank statement. The request checker searches our limited official-source collection. It does not find sufficient support, so it returns: needs official clarification. Missing information is not proof that the request is unlawful. The result suggests asking which published instruction and circumstance supports the request. |
| 122–149s | Record request; create Bangla letter; edit; download | We record that request as a citizen-reported event, clearly distinct from an authenticated government record. Then we create a respectful clarification draft in Bangla or English. The citizen can select references, edit the wording, and download it. CivicProof never sends a complaint or application automatically. Each next action stays under the citizen's control. |
| 149–175s | Docs; actual evaluation; model inventory; return overview | The technical portal shows what actually runs: local Tesseract OCR, conservative validation, bilingual keyword retrieval, and deterministic letter templates. Our next steps are specialist rule review, stronger OCR evaluation, and secure production case storage. CivicProof: transparent requirements, verifiable actions, empowered citizens. |
